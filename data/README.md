# Dataset source

This project uses the **Online News Popularity** dataset from the UCI Machine Learning Repository:

- Dataset page: https://archive.ics.uci.edu/dataset/332/online+news+popularity
- DOI: https://doi.org/10.24432/C5NS3V
- Observations used after preparation: 39,644
- Primary outcome: `shares`

The source and prepared data are retained inside the Assignment 2 Excel workbook. The large raw dataset is not duplicated in this folder, keeping the repository organized while preserving the exact submitted coursework.
